# WenRadar

Painel web para organizar informações públicas de perfis do Instagram, com foco em transparência e limites de acesso.

## Estado atual

**Fase 1: interface demonstrativa.** O site ainda não consulta o Instagram. A pesquisa apenas demonstra como o painel poderá organizar as informações; os resultados são avisos de demonstração, não dados reais.

## Como abrir

Abra `index.html` no navegador ou ative o GitHub Pages nas configurações do repositório.

## Próximas etapas

1. Publicar a interface no GitHub Pages.
2. Escolher e conectar uma fonte de dados permitida, verificando as permissões e os limites aplicáveis.
3. Implementar resultados reais, tratamento de erros e limites de requisição.
4. Se a fonte permitir, registrar coletas ao longo do tempo para formar um histórico de observação.

## Limites e privacidade

- O site não pede senha do Instagram.
- Não tenta acessar perfis privados, contornar bloqueios ou usar sessões falsas.
- Não promete histórico universal de curtidas nem de vídeos/Reels assistidos por outras pessoas.
- Os dados disponíveis dependem da fonte, das permissões concedidas e das regras atuais do Instagram.

## Tecnologias

HTML, CSS e JavaScript puro. Sem dependências externas na interface inicial.
